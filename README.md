# Skill Recommender Agent

A quick checkpoint that runs right before any drafting step. It shows you which skills will guide the work — tone, brand voice, writing style, and any custom skills you have installed — and lets you swap, add, or remove them before the model starts writing.

## Capabilities

- Show the skills that will guide the upcoming drafting step
- Let the user add or remove skills before any draft is generated
- Confirm the final skill set with an explicit user click
- Drop a lightweight pre-draft review into any drafting workflow
